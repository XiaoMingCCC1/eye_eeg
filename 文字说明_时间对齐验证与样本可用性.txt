════════════════════════════════════════════════════════════════════
1.0 结论先行
════════════════════════════════════════════════════════════════════
(1) 对齐的目标是"把瞳孔序列放到 EEG 参数点的原生时间网格上"，不是把
    两路信号重采样到某个新采样率。目标网格由 EEG 侧决定：第 k 个参数点
    的中心在 (k+1) 秒，相邻中心间隔正好 1 秒。
(2) 对齐只做两件事：中心前后 0.5 秒内有实测瞳孔样本就直接取实测；没有
    实测但左右相邻实测点间隔不超过 2 秒就做线性插值。两种情况都不满足
    就记该点为无效——不填补、不置 0、不外推。
(3) 无效点会切断"连续有效区间"。三条件各自取自己最长的连续有效段，
    再取三者的最小值 n_i 作为共同点数，每条条件都取最早能容纳 n_i 点的
    窗口。因此三条件的点数与步长完全相同，起点可以不同，且绝不拼接。
(4) 已实测核对：38 人 × 3 条件共 114 段的 valid_fraction 全部 = 1.0，
    中心间隔全部为 1.000 s，首点中心 = 起点索引 + 1。插值点占比最高
    20.6%（正性条件），未出现跨长缺口插值。
(5) 未建模的部分必须说明：视频开始到记录开始之间的绝对偏移没有对齐，
    因此只能说"两信号共用同一相对时间索引"，不能声称毫秒级同步。

1.1 两条原始时间轴
════════════════════════════════════════════════════════════════════
(1) EEG 侧：SPRiNT 单试次参数
    参数来源：SPRiNT_parameters_*.log，每个通道每个时间点一组
             offset（偏移）与 exponent（1/f 斜率）。
    窗长    ：WinLength = 2 s
    重叠    ：50%，即步长 = 1 s
    中心时刻：第 k 个参数点（k 从 0 开始）的中心 = (k+1) s，
             覆盖的支持区间 = [k, k+2] s。
    日志格式：文件头写 "形状: (n_tp, 121)"，其中
             121 = 0–60 Hz、步长 0.5 Hz 的频率 bin 数，
             n_tp 才是时间点数（这一点早期曾被误读为 121 个通道，已纠正）。
    n_tp 实测分布（按视频批次）：
             v1：93 / 103 / 121
             v2：177 / 285 / 356
             v3：121 / 300 / 300
    结论：EEG 的时间分辨率是 1 s，不是原始采样率；所有后续对齐都以
          "k+1 秒"这一条网格为准。

(2) 眼动侧：瞳孔序列
    原始采样：120 Hz
    预处理  ：STFT，窗长 2 s，50% 重叠，winaverage = 0
    输出    ：每个时间点一个瞳孔值，序列首点 ≈ 1.0010 s，
             相邻点间隔 ≈ 1.0010 s（不是严格的 1.0000 s）
    数据缺陷：全库最大缺口 155.218 s；有 90 个瞳孔日志文件存在
             大于 2 s 的采样间隔（多为眨眼、丢眼或分段记录造成）。
    结论：瞳孔序列"名义上"接近 1 Hz 网格，但与 EEG 的整数秒网格存在
          ~1 ms/点 的漂移，且存在长短不一的缺口，不能直接按行号对齐。

1.2 对齐算法的逐步实现
════════════════════════════════════════════════════════════════════
函数：pair_pupil_to_params(pl, n_tp, tol_direct=0.5, max_gap=2.0)
位置：mi_robustness_analysis.py 第 315–360 行

步骤 1  构造目标网格
        centers = np.arange(n_tp, dtype=float) + 1.0
        即 1.0, 2.0, 3.0, …, n_tp 秒。
        与 1.1(1) 的 "第 k 点中心 = k+1 秒" 一致。

步骤 2  清洗瞳孔序列
        ok = isfinite(t) & isfinite(y)，只保留时间与数值都有限的样本。
        （这一步只删坏点，不产生新点。）

步骤 3  为每个中心找左右邻点
        right = searchsorted(t, centers, side="left")
        left  = clip(right-1, 0, n-1);  right = clip(right, 0, n-1)
        d_left = |center - t[left]|,  d_right = |center - t[right]|
        取距离更近的一侧作为"最近实测点"，距离记为 d_near。

步骤 4  规则一：最近实测在容差内 → 直接取实测
        if d_near <= 0.5 s:  vals = 该实测值, valid = True, interp = False
        容差 0.5 s 的取法理由：EEG 步长是 1 s，0.5 s 正好是半个步长，
        保证任何一个中心点最多只会"借用"相邻一个格子的实测值，
        不会把相距一个完整步长以上的瞳孔值搬到该中心上。

步骤 5  规则二：无实测但缺口可接受 → 线性插值
        need = ~direct
        gap  = t[right] - t[left]
        条件：need 且 right != left 且 gap <= 2.0 s
        权重：w = (center - t[left]) / (t[right] - t[left])
              vals = y[left] + w * (y[right] - y[left])
              valid = True, interp = True
        上限 2.0 s 的取法理由：瞳孔预处理窗长就是 2 s，缺口超过 2 s 时
        两端样本已不属于同一个有效分析窗，插值出来的值没有观测支撑。

步骤 6  规则三：超出观测范围 → 无效
        outside = (center < t[0] - 0.5) | (center > t[-1] + 0.5)
        valid[outside] = False
        即瞳孔记录开始前与结束后的 EEG 中心点一律记无效，不外推。

步骤 7  返回三个等长数组
        vals   对齐后的瞳孔值（无效处保持 NaN）
        valid  该中心点是否有可用瞳孔值（实测或插值）
        interp 该点是否为插值（用于统计插值占比）

关键设计取舍（为什么不是"重采样到 120 Hz 再降采样"）：
    重采样会让插值跨越长缺口而没有被察觉，且会把 155 s 的空档"平滑"成
    看似连续的序列。当前做法把"是否可插值"变成显式判据（gap <= 2 s），
    超过就留下空洞并由下游切成无效段，代价是个别被试点数减少，收益是
    不会凭空制造数据。这也是规范"无效点不填补、不置 0"的直接落实。

1.3 无效点如何决定可用片段
════════════════════════════════════════════════════════════════════
函数：run_info / valid_runs / pick_start（第 363–377、724–748 行）

(1) 逐点有效性
    在 load_subject_block 中，最终有效掩码为：
        valid = pvalid  &  isfinite(offset)  &  isfinite(exponent)
    即：瞳孔必须可用，且该被试共同通道集里所有通道的 offset 与 exponent
    在该时间点都必须是有限值。任何一路缺失，该点即无效。

(2) 连续段
    run_info(valid) 返回 (最长连续有效段长度, 所有连续段列表)。
    无效点不被跳过、不被填补，而是直接把序列切成两段。因此一个 155 s
    的瞳孔缺口会真实地体现为"该被试在这段没有可用片段"。

(3) 三条件等长
    n_i = min(三条件各自的最长连续有效段长度)
    这一步保证"三条件点数完全相同"，是本轮等长片段分析的核心约束。

(4) 取窗规则
    native_equal / k5 / k10 / legacy_same_cohort：
        mode = "earliest_ni" → 每条条件取最早一个长度为 n_i 的窗口起点
        （pick_start 返回该条件第一条长度 ≥ n_i 的连续段的起点）
    native_global_equal：
        mode = "earliest_global" → 每条条件取最早一个长度为 n_global 的窗口
        （n_global = 全体被试 n_i 的最小值 = 23 点）
    position_early / middle / late：
        先冻结 n_position = 80，再按位置取窗：
          early  = 最早一个 80 点窗口
          late   = 最晚一个 80 点窗口
          middle = 在所有 80 点候选中，取窗口中点最接近"视频名义中点"的那个
                   （视频名义时长 100/280/120 s → 名义中点 50/140/60 s；
                    事件记录不可得，故不用真实事件时刻）
    三种位置都只改起点，不改点数、不改步长、不改通道。

(5) 窗口的物理含义
    start_index = s（0-based）
    首个中心时刻 = s + 1 秒
    支持区间     = [s, s + n_i + 1] 秒
    中心跨度     = (n_i − 1) 秒
    例：n_i = 58 时，58 个中心点跨 57 秒，覆盖 59 秒支持区间。

2.3 参数拟合的可用性
════════════════════════════════════════════════════════════════════
这里"参数拟合"指 SPRiNT 单试次拟合出的 offset 与 exponent 两个参数，
以及它们进入 MI 估计前必须满足的点数与有限性条件。

(1) 拟合本身
    offset / exponent 由 SPRiNT 预先算好并写入日志，本流水线只做解析，
    不重新拟合；因此"拟合失败"体现为日志缺失、通道缺失或非有限值。
    实测：38 名被试在三条件下 x / y / t 全部为有限值（自检 9 项之一）。

(2) 点数条件（KSG 估计）
    主分析 k = 3：要求 n > k；敏感性 k = 5、k = 10：要求 n > 10。
    38 人的 n_i 分布：最小 23，P25 = 99，中位 99，P75 = 99，最大 100，
    均值 92.4，标准差 16.3。
    → 全部满足 k = 10 的要求，没有被试因点数不足被剔除。
    → 全部满足 n_min = 20 的下限（规范 L40–52 要求不得把 15/18 点当可靠
      标准，故下限设为 20）。

(3) 通道条件
    被试内取三条件的共同通道（交集），保证同一被试三个条件通道完全一致。
    实测：107 通道 37 人，119 通道 1 人。

2.6 原主分析 23 人 vs 其余 74 人
════════════════════════════════════════════════════════════════════
(1) 为什么不能直接比较 23 与 74
    四条证据表明原主分析的 23 人名单不可复原：
      a. ouhe\results_jingxi 下三个 pac_coupling_detailed_*.csv 均只剩
         1 名被试（S03），无法还原 23 人；
      b. 同目录配对检验 8 行全部为 n_subjects = 1 / not_evaluable；
      c. ouhe\results_2\pac_region_video_stats.csv 记录的旧配对人数是
         28 / 30 / 24，与 23 不一致；
      d. 稿件正文中检索不到 "23" 这个数字。
    → 因此"23 vs 74"不能作为可复现的对照写进方法或结果。

(2) 采用的替代对照：本轮 38 人 vs 公开表中其余 55 名 18 岁以下被试
    分母：93 − 38 = 55（公开表口径，可复核）

    年龄
        38 人：12.05 ± 2.62 岁（范围 6–17）
        55 人：11.51 ± 2.80 岁（范围 8–17）
        Mann–Whitney U = 1190，p = 0.2559
        → 无统计学差异

    性别（1 = 男，2 = 女）
        38 人：27 男 / 11 女（女性 28.9%）
        55 人：27 男 / 28 女（女性 50.9%）
        χ²（Yates 校正）= 3.60，p = 0.0579
        χ²（未校正）      = 4.45，p = 0.0349
        Fisher 精确检验    p = 0.0538
        → 女性比例偏低，处在 0.05 边界附近；按预先设定的 α = 0.05 判为
          不显著，但效应方向明确（可选样本中女性偏少），必须在限制中写明。

(3) 结论与建议措辞
    "原主分析的 23 人名单在现有交付结果中不可复原，故未做 23 vs 74 的
     直接比较；改用可复核的对照：本轮 38 名可分析被试与公开表中其余
     55 名 18 岁以下被试相比，年龄无显著差异（12.05 ± 2.62 vs
     11.51 ± 2.80，p = 0.256），女性比例偏低但未达显著
     （28.9% vs 50.9%，χ² = 3.60，p = 0.058；Fisher p = 0.054）。"
    注意：55 人年龄下限是 8 岁（38 人是 6 岁），比较时不要写成两组范围相同。

【时间对齐】
"EEG 侧采用 SPRiNT 的 2 s 分析窗、50% 重叠，参数点的步长为 1 s，第 k 个
参数点的中心位于 (k+1) s。眼动侧为 120 Hz 原始瞳孔信号经 2 s 窗、50%
重叠的时频变换后的逐点输出。对齐时以 EEG 参数点中心为目标网格：若中心
前后 0.5 s 内存在瞳孔实测样本则直接取用；若不存在但左右相邻实测样本的
间隔不超过 2 s，则做线性插值；其余情况（缺口大于 2 s 或超出观测范围）
一律记为无效，不填补、不置 0，并由无效点切断连续有效区间。随后在同一
被试内取三条件最长连续有效段的最小值作为共同点数，每条条件取最早能容纳
该点数的窗口，因此三条件的点数与步长完全一致且不做拼接。实测 38 名被试
× 3 条件共 114 段，窗口内有效点占比均为 1.0，插值点占比最高 20.6%，
中心间隔均为 1 s。该方法对齐的是相对时间索引，未对视频起始与记录起始
之间的绝对偏移建模，因此不声称毫秒级同步。"
